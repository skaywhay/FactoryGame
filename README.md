# Factory Game

Управленческая симуляция завода в реальном времени. Игрок строит производственные линии, управляет энергией, выполняет дневные планы и развивает завод от простой шестерёнки до сложных турбин.

## Описание

Factory Game — это экономическая симуляция, где вы управляете небольшим заводом. Задача — выполнять ежедневные производственные планы, балансировать доходы и расходы, вовремя убирать брак и расширять производство.

Игра рассчитана на сессии по 15–30 минут. Каждая смена длится 40 секунд реального времени. За день нужно выполнить план по конкретным деталям — просто «заработать денег» недостаточно.

## Основные механики

### Производственные линии
Три типа линий, открывающихся последовательно:

| Линия | Продукт | Сырьё на 1 шт | Базовое время | Стоимость постройки |
|-------|---------|---------------|---------------|---------------------|
| 1 | Шестерёнки | 1 | 1.6 сек | Бесплатно |
| 2 | Корпуса | 2 | 3.2 сек | $180 |
| 3 | Микросхемы | 3 | 4.8 сек | $420 |

Каждая линия состоит из трёх станков:
- **Закупчик** — покупает сырьё партиями по 2 штуки
- **Производитель** — делает товар из сырья
- **Продавец** — продаёт готовый товар

### Энергия
- Каждый станок потребляет энергию (на уровне 1 — 2 единицы, дальше +1 за уровень)
- Два генератора дают по 4 энергии на первом уровне
- Если потребление превышает генерацию — завод встаёт
- Генераторы требуют ежедневную оплату топлива (инфляция растёт 7% в день)

### Улучшения
- Максимальный уровень станка: 15
- Каждый уровень: +28% скорости, +1 энергия потребления
- Цена улучшения растёт в 1.45 раза за уровень

### Сборка (продвинутое производство)
Три рецепта, открываемые вкладкой «Сборка»:

| Продукт | Ингредиенты | Базовая цена | Время | Энергия |
|---------|-------------|--------------|-------|---------|
| Редуктор | 2 Шестерёнки + 1 Корпус | $90 | 7 сек | 3 |
| Привод | 1 Редуктор + 2 Микросхемы | $260 | 11 сек | 3 |
| Турбина | 2 Привода + 3 Корпуса | $700 | 16 сек | 3 |

Сборка выгоднее прямой продажи деталей, но требует цепочку производства.

### Дневные планы
Каждый день генерируется план с конкретными целями по деталям. Примеры первых дней:
- День 1: 12 шестерёнок
- День 3: 17 шестерёнок + 4 корпуса
- День 7: 24 шестерёнки + 11 корпусов + 3 микросхемы + 1 редуктор
- День 12+: план растёт на 8% в день

Выполнение плана даёт премию. Провал — страйк. 3 страйка — конец игры.

### Брак
- До 2 раз за смену на случайной линии появляется красная деталь
- 12 секунд на устранение кликом (в 3D-зале или кнопкой в HUD)
- Просрочка: -1 готовый товар со склада линии
- Устранение: +$5

### Инфляция
- Цены сырья, продажи и постройки растут на 7% в день
- Зарплаты (топливо генераторов) тоже растут
- Принуждает к постоянному расширению производства

## Управление

| Действие | Клавиша / UI |
|----------|--------------|
| Пауза / продолжение | Пробел или кнопка «ПАУЗА» вверху |
| Убрать брак | Клик по красной детали в зале или по красной плашке сверху |
| Улучшить станок | Карточка линии в сайдбаре → кнопка улучшения |
| Построить линию | Карточка непостроенной линии → кнопка постройки |
| Открыть сборку | Вкладка «СБОРКА» над карточками линий |
| Таблица статистики | Кнопка «ТАБЛИЦА» вверху |
| Обучение | Кнопка «ОБУЧЕНИЕ» вверху (доступно повторно) |

## Обучение
При первом запуске автоматически открывается обучение (5 шагов):
1. Пауза — остановить и запустить смену
2. Брак — убрать учебную бракованную деталь
3. Улучшение — повысить уровень закупщика на линии шестерёнок
4. Сборка — открыть вкладку сборки
5. Новая линия — построить линию корпусов

Смена во время обучения не идёт, случайный брак не появляется. Пройти можно за 1–2 минуты.

## Технические детали

### Архитектура
- **FactorySim** — чистая симуляция (без Unity-зависимостей), вся математика
- **FactoryGame** — связка симуляции, 3D-зала и HUD
- **HallBuilder** — процедурально строит 3D-зал из Kenney Factory Kit
- **Hud** — весь UI на кодогенерированных UI-элементах (без префабов)

### Ассеты
- 3D-модели: [Kenney Factory Kit](https://kenney.nl/assets/factory-kit) (CC0)
- Шрифт: Bahnschrift (встроен в Windows) / fallback — LegacyRuntime / Arial
- Партикл-эффекты: свои, в Resources/UI/Effects

### Требования
- Unity 2022.3 LTS или новее
- .NET Standard 2.1
- URP / Built-in Render Pipeline (работает в обоих)

### Структура проекта
```
Assets/
  Scripts/Factory/
    FactorySim.cs     # Симуляция (экономика, линии, планы, брак)
    FactoryGame.cs    # Главный MonoBehaviour, Update, ввод
    Hall.cs           # 3D-зал, Station, LineView, HallBuilder
    Assembly.cs       # Рецепты сборки, AssemblyLine
    Hud.cs            # Весь UI: сайдбар, баннеры, обучение, практика
  Editor/
    FactorySetup.cs   # Настройка проекта из меню Tools
  Resources/
    UI/Effects/       # Партикл-префабы (__MoneyRain, __Smoke, __GetMoney, __AssembleEnd)
    UI/Sprites/       # UI-спрайты (кнопки, баннеры)
    UI/Fonts/         # Bahnschrift.ttf
    FactoryKit/       # Модели Kenney (FBX + текстуры)
```

## Запуск в редакторе
1. Открыть проект в Unity 2022.3+
2. Сцена: `Assets/Scenes/SampleScene.unity` (или создать новую)
3. На пустом GameObject повесить `FactoryGame`
4. Play

Или через меню: `Tools → Factory → Setup Scene` — создаст сцену автоматически.

## Баланс (кратко)
- Стартовые деньги: $300
- Длина смены: 40 сек
- Премия за план: $80 + $35 за каждый день
- Топливо генераторов списывается в начале дня
- Если денег на топливо нет — субсидия +$30 к долгу, смена пропускается, страйк
- Склады линий: 10 сырья / 10 готово — намеренно малые

## Известные ограничения
- Нет сохранения игры между сессиями (только флаг пройденного обучения в PlayerPrefs)
- Нет звука
- 3D-зал статичен, камера не управляется
- UI не адаптивен под нестандартные соотношения сторон (CanvasScaler: MatchWidthOrHeight 0.5)
